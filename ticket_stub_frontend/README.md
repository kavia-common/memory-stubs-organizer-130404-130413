# Stub Scrapbook — Cute React Frontend

A playful, scrapbook-styled React UI for organizing your ticket stubs and memories. The interface uses rounded shapes, pastel accents, and delightful doodles/washi tape motifs. It includes grid and scrapbook views, an upload modal, a details drawer, and a filter/search sidebar.

## Tech
- React 18 + react-scripts
- Pure CSS (no UI frameworks)

## Theme
- Primary: #5636d3
- Secondary: #f6f7fb
- Accent: #ffbf47
- Fonts: Baloo 2, Quicksand (Google Fonts)

## Features (UI Scaffold)
- User badge (avatar), navigation bar, and view toggle
- Upload modal with image preview and form fields
- Grid and scrapbook views for tickets
- Details drawer to edit ticket info
- Search and filter by year/type
- Responsive layout

## Getting started
- npm start
- Visit http://localhost:3000

Note: Backend API/auth is not wired yet. The UI uses demo data in memory.
